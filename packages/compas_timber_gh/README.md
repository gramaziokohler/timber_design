# compas_timber_gh

Grasshopper component helpers (Python package) and the sources of two Yak packages:

* `components/core` – core COMPAS Timber components, including joint rules (requires `compas_timber_rules`).
* `components/populator` – PanelPopulator add-on components. **Requires the core Yak package** to be installed.

Part of the [timber_design](https://github.com/gramaziokohler/timber_design) monorepo.
